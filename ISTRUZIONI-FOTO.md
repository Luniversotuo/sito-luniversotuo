# Istruzioni per inserire le foto

Tutte le foto vanno messe nella cartella `img/` con questi nomi esatti:

## Logo (già caricato — rinominare il file)
- `logo-luniversotuo.png` → logo principale LuniversoTuo
- `logo-superserenita.png` → solo il marchio SuperSerenità®

## Foto team
- `foto-giancarlo.jpg` → foto Giancarlo (card piccola homepage)
- `foto-giancarlo-hero.jpg` → foto Giancarlo (hero homepage, verticale)
- `foto-giancarlo-full.jpg` → foto Giancarlo (pagina team, grande)
- `foto-francesco.jpg` → foto Francesco (card piccola)
- `foto-francesco-full.jpg` → foto Francesco (pagina team)
- `foto-elisabetta.jpg` → foto Elisabetta (card piccola)
- `foto-elisabetta-full.jpg` → foto Elisabetta (pagina team)
- `foto-gabriele.jpg` → foto Gabriele (card piccola)
- `foto-gabriele-full.jpg` → foto Gabriele (pagina team)
- `foto-sara.jpg` → foto Sara (card piccola)
- `foto-sara-full.jpg` → foto Sara (pagina team)

## Foto storie
- `storia-mattia.jpg` → immagine per la storia di Mattia
- `storia-lavinia.jpg` → immagine per la storia di Lavinia
- `storia-riccardo.jpg` → immagine per la storia di Riccardo

## Note
- Tutte le foto vengono applicate automaticamente in bianco e nero via CSS (filter: grayscale(100%))
- Non serve convertirle prima — il sito lo fa automaticamente
- Se una foto non si trova, il sito mostra un placeholder blu tratteggiato con le istruzioni
- Formato consigliato: JPG, minimo 800px di larghezza
